You don't need a cluster to prove Kafka and Flink scale linearly

You need a laptop, one broker, and about four minutes per data point.

Claude Code built the whole thing — the pipeline, the test suite, the measurement harness, the CI, the dashboards and the deck. It cost about six hours of my own time at the keyboard.

The pipeline turns block trades into positions and market value, exactly-once, with every output verified against real Kafka topics. Then I measured what one more core actually buys. The answer is: almost exactly one more core's worth.

[LEAD IMAGE: docs/img/scaling-linear.png]

• 1 core — 30,505 orders/sec
• 2 cores — 65,721 orders/sec, 2.15× the previous
• 4 cores — 129,056 orders/sec, 1.96× the previous

Four times the resources, 4.23× the throughput. On a laptop. One Kafka broker. One docker compose command.

At four cores that is 129,056 orders per second in and 645,280 records per second out, because every order fans out to five records: four account-side allocations plus one symbol-side position.

Flink 1.20, Kafka 3.9, Java 17, all in Docker.
