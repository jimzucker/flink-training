You don't need a cluster to prove Kafka and Flink scale linearly

129,056 block trades a second, on a laptop with one Kafka broker. Exactly-once, with every output verified against the real topics.

Claude Code built the whole thing — the pipeline, the test suite, the measurement harness, the CI, the dashboards and the deck. It cost about six hours of my own time at the keyboard.

[LEAD IMAGE: docs/img/scaling-linear.png]

Orders in, per second:

• 1 core — 30,505/sec
• 2 cores — 65,721/sec, 2.15× the previous
• 4 cores — 129,056/sec, 1.96× the previous

Four times the cores, 4.23× the throughput. Nothing varies but the cores: eight partitions throughout, each case draining a 50,000,000-order backlog with the producer stopped.

One docker compose command, about four minutes per data point.

Flink 1.20, Kafka 3.9, Java 17, all in Docker.
