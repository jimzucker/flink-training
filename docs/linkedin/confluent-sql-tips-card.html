Flink SQL · Confluent Cloud

Nine tips for benchmarking Flink SQL on Confluent Cloud

From running one SQL statement, unchanged, on a laptop and on Confluent Cloud.

  1. 1Make the job use the whole pool: set baseline_cfu
  2. 2Use a partition count that divides evenly by every pool size
  3. 3Give Kafka enough capacity for your largest pool
  4. 4Count test data by reading it, not from the topic's size
  5. 5Check results with a snapshot query
  6. 6Create a new compute pool for each size
  7. 7Wait for the usage figures before measuring
  8. 8Delete what a test creates, even after a crash
  9. 9Allow for the cost report's one-day delay
