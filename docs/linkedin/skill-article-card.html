prove-it-scales · a Claude Code skill

A scaling benchmark that refuses bad numbers.

Supply a Flink job, a deterministic generator and a verifier. One command proves nothing is lost, measures every case at least twice, and refuses to publish a result the checks don't support.

up→ preflight→ completeness→ tiny proof→ fill→ suite→ report

Stops at the first step that doesn't pass. Completeness drains to the last record and checks every key exactly, then again after a worker is killed mid-drain.
