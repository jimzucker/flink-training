# Skills

Skills in this directory are picked up automatically by Claude Code for anyone
working in this repository — clone it and `/scalable-flink-skill` is available with no
setup.

To use one outside this repo, copy it to your own skills directory:

```bash
cp -r .claude/skills/scalable-flink-skill ~/.claude/skills/
```

| skill | what it does |
|---|---|
| `scalable-flink-skill` | Interviews you one question at a time about a pipeline you want to build and prove scales, then enforces the measurement discipline that makes the resulting numbers defensible. Written from what this project got wrong the first time. |
